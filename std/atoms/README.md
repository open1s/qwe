# `std/atoms/` — schematic atomic internal structure

Each module declares a `shape <Sym>_atom` you can attach to an entity:

```pwe
import "std/atoms/O"
world { gravity = (0, 0, 0) entity Oxygen { shape = O_atom; size = 2.5 } }
```

The shape shows the atom's **internal form**:

- the **nucleus** — protons (red) and neutrons (grey) on a small sphere,
  proportional to the real nucleon mix;
- one **shell ring** per occupied shell;
- **electrons** (blue) that **orbit** each shell (inner shells faster), animated
  over simulation time by the viewer.

Heavy nuclei and large shells are drawn **schematic** (≤ 12 nucleons, ≤ 4
electrons per shell) so the shape stays legible. `size` on the entity scales the
whole atom. Numeric data lives in `std/elements/`; this package is presentation
only. Generated by `tools/gen_atoms.py` — do not edit by hand.

A demo lives at `cli/examples/atom.pwe`.
