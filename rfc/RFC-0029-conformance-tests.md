# RFC-0029: Conformance and Test Requirements
**Status:** Normative. Version-controlled fixtures MUST cover canonical schema/WIR/EIR round-trip and rejection, transaction atomicity/stale handles, deterministic replay hashes, duplicate distributed messages/epochs, interpreter-JIT-AOT differential semantics, JIT deopt, render version consistency, and CPU/GPU fences. Property tests generate bounded valid schemas/graphs/transactions/deltas. Any silent divergence fails conformance. Report implementation version, profile, fixture hashes, passed/failed/skipped tests; skipped REQUIRED tests prohibit a claim.
