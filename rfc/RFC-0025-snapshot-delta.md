# RFC-0025: Snapshot and State Delta
**Status:** Normative. Snapshot header contains SchemaSetHash, WorldVersion, SimTime, ownership epochs, entity table, authoritative component values, and resource refs. Delta has one BaseWorldVersion and TargetWorldVersion and sorted operations: Create/Destroy Entity, Add/Remove/Replace/Patch Component, ResourceUpdate, OwnershipUpdate, EventBatch. Apply validates base/schema/epoch/order then uses one transaction; it either reaches target or changes nothing. Compression is RFC-0036 transport policy and never changes canonical semantic bytes.
