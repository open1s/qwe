# RFC-0022: Memory and Concurrency Semantics
**Status:** Normative. Runtime alone owns authoritative storage. `ReadView` permits concurrent reads; `WriteView` is exclusive for its declared component/entity slice. Scheduler-declared dependencies establish happens-before; undeclared conflicts fail validation. Atomics are Relaxed/Acquire/Release/AcqRel/SeqCst only. Normal writes become authoritative only at RFC-0023 Commit. CPU/GPU transitions require explicit fence plus ownership transfer. Plugin/backend calls MUST declare accesses and cannot hide a data race. A view expires at transaction end; use after expiry is `PWE_E_HANDLE_STALE`.
